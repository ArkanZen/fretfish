## 1. 背景与目标

用户是电吉他初学者，难以记住指板上的把位。目标是做一个跑在浏览器里的 Web 应用，
帮助记忆指板上每个位置对应的 **音名**、**简谱唱名** 和 **音阶指型/把位**，
既能当可交互的参考图查阅，也能出题测验来强化记忆。

参考资料：用户提供的两张指板图（音名图 + 简谱图 + 五个指型把位图 Sol/La/Si/Re/Mi）。

## 2. 范围（v1）

### 做什么
- 标准调弦六弦吉他（1 弦 = 高音 E 在上，6 弦 = 低音 E 在下），0–12 品。
- 三种内容图层，可切换：
  - **音名**：C D E F G A B（含 `显示升降音` 开关补 #/♭）
  - **简谱唱名**：1234567（do re mi…），**固定 C 调**（1=C）
  - **音阶指型/把位**：Sol / La / Si / Re / Mi 五个把位，用彩色区域圈出
- 两大模式：
  - **参考模式**：可交互指板，点击任意位置在下方展示区看详情。
  - **练习模式**：出题测验 + 计分，含两种出题方向。
- **点击发音**：用 Web Audio API 合成音色，无需外部音频文件；可开关。
- **桌面应用（Tauri）+ 摸鱼模式**：打包成 macOS 桌面应用；提供一个紧凑悬浮窗：
  - 无边框 / 窗口透明、背景半透明
  - 始终置顶（盖在工作软件之上）
  - 可调透明度（滑块）、可调窗口大小、内容缩放
  - 全局快捷键一键隐藏/呼出（老板键）
- 桌面应用窗口可缩放；网页内容布局响应式（指板可横向滚动）。

### 不做（v1 明确排除，留待以后）
- 切换调（除 C 调外的移动 do）—— 但数据模型按"调"组织，预留扩展。
- 真实吉他采样音色、节拍器、和弦库、曲谱播放。
- 账号系统 / 云端同步（成绩仅存本地 localStorage）。
- 自定义调弦（Drop D 等）。

## 3. 技术方案

- **前端框架**：Vue 3（Composition API）+ Vite。
- **桌面壳**：Tauri 2（Rust）。复用同一套 Vue 前端，`tauri dev / tauri build` 产出桌面应用。
  - 需要本机 Rust 工具链（rustup/cargo）+ Tauri 前置依赖。
- **样式**：原生 CSS（或 scoped CSS），不引入 UI 框架，保持轻量。
- **音频**：Web Audio API（OscillatorNode + 包络），按 (弦, 品) → 频率换算合成。
- **持久化**：`localStorage` 保存设置（最近模式/内容/开关/窗口偏好）与练习历史成绩。
- **架构**：纯前端逻辑 + Tauri 提供窗口能力；前端在浏览器里也能独立运行调试
  （摸鱼相关的窗口控制在浏览器环境降级为不可用，不影响其余功能）。

### Tauri 窗口与摸鱼模式
- 主窗口正常模式：常规带边框窗口。
- 摸鱼悬浮窗（可切换或独立窗口）：
  - `decorations: false`（无边框）、`transparent: true`（窗口透明）、`alwaysOnTop: true`。
  - 透明度：通过 `window.setIgnoreCursorEvents` 不需要，用 `set_opacity`/CSS 背景透明度调节整体可见度。
  - 全局快捷键（`tauri-plugin-global-shortcut`）：注册老板键，切换窗口显示/隐藏。
  - 窗口大小由用户拖拽；内容缩放用前端 CSS `transform: scale` 或根字号控制。
  - 拖动：无边框窗口用 `data-tauri-drag-region` 指定可拖拽区域。

## 4. 架构与组件拆分

```
App.vue                  顶层：模式状态、内容状态、全局开关
├─ Toolbar.vue           模式(参考/练习) + 内容(音名/简谱/指型) + 开关(升降音/发音) + 范围
├─ Fretboard.vue         指板渲染：弦枕、品格、品格点、品位号、音点
│   └─ FretCell (内部)   单个 (弦,品) 单元：渲染音点、处理点击
├─ NoteInfoBar.vue       参考模式下方「当前选中」横向卡片
├─ ZenModeBar.vue        摸鱼模式控制条：透明度滑块/置顶开关/缩放/拖拽区/隐藏
├─ practice/
│   ├─ QuizPanel.vue     练习模式容器：题目进度 + 计分条 + 出题调度
│   ├─ QuizAnswerToFret  方向 B：看音名→在指板点位置
│   └─ QuizFretToAnswer  方向 A：看位置→选项选音名
└─ (composables)
    ├─ useFretboard.js   生成指板数据模型（弦/品/音名/简谱/指型归属/根音）
    ├─ useAudio.js       Web Audio 发音
    ├─ useQuiz.js        出题、判分、连对、计时、成绩存储
    └─ useWindow.js      封装 Tauri 窗口能力（置顶/透明度/隐藏/拖拽）；
                         非 Tauri 环境下降级为 no-op
```

Tauri 侧（`src-tauri/`）：窗口配置 `tauri.conf.json` + 全局快捷键注册（Rust 入口）。

每个组件职责单一、通过 props/emit 通信，可独立理解和测试。

## 5. 数据模型

### 5.1 常量
- 弦的空弦音（1→6 弦）：`['E','B','G','D','A','E']`
- 十二平均律音序：`['C','C#','D','D#','E','F','F#','G','G#','A','A#','B']`
- C 大调简谱映射：`{C:'1', D:'2', E:'3', F:'4', G:'5', A:'6', B:'7'}`（仅自然音有唱名）
- 升降音在简谱中标记为相邻数字的 #/♭（v1 默认隐藏升降音，可不显示唱名）。

### 5.2 单元格对象（每个 弦×品 计算一次）
```js
{
  string: 3,          // 弦号 1..6
  fret: 5,            // 品 0..12（0 = 空弦/弦枕）
  note: 'C',          // 音名
  isNatural: true,    // 是否自然音
  solfege: '1',       // C 调简谱唱名；升降音时为 null 或带 #
  isRoot: false,      // 是否当前根音（C 调以 C 为根，或按内容定义）
  shapes: ['Sol'],    // 所属指型（可能属于多个把位的重叠区）
}
```
> 说明：`useFretboard` 由空弦音 + 品数推算 `note`；`shapes` 由各指型的 (弦,品) 区间定义表查表得到。指型定义以"五个把位的覆盖范围 + 各音位置"硬编码为常量表（参照参考图）。

### 5.3 指型定义（Sol/La/Si/Re/Mi）
以一张常量表描述每个把位覆盖的品位区间和包含的音点（来源：用户参考图2）。
v1 以 C 调音阶的五个把位位置为准。该表是后续切调扩展的关键，需准确录入。

## 6. 交互细节

### 参考模式
- 指板按内容图层显示对应标注（音名/简谱数字/指型彩色区）。
- 点击任意音点：该点黄色高亮，下方 `NoteInfoBar` 显示
  音名 / 简谱(C调) / 位置(几弦几品) / 所属指型 / 是否根音，并发音；按钮可重听。
- 根音以红色点区分。
- `显示升降音` 关：仅显示自然音点（与参考图一致）；开：补全所有 12 音位置。
- `指型` 内容下：用半透明彩色框/底色圈出 Sol/La/Si/Re/Mi 区域并标注名称。

### 练习模式
- 顶部计分条：第 N 题 / 共 M 题、正确数、错误数、连对(streak)、计时。
- `范围` 限制出题区域：全指板 / 低把位(1–5品) / 仅自然音，降低初学难度。
- **方向 A（看位置→答音名）**：指板高亮一个随机位置，下方 4 个选项（音名/简谱/指型，按当前内容），选对变绿、选错变红并标出正确项，自动进入下一题。
- **方向 B（看音名→点位置）**：给出一个目标音/简谱，要求在指板上点出其所有位置；点对亮绿、点错亮红，全部找到后进入下一题。
- 一轮结束显示成绩小结（正确率、用时、最高连对），成绩存 `localStorage`。

### 摸鱼模式（仅桌面应用）
- 入口：工具栏一个「摸鱼」开关，进入紧凑悬浮窗形态。
- 控制条 `ZenModeBar`：
  - 透明度滑块（整窗可见度）。
  - 始终置顶开关。
  - 内容缩放（+/-）。
  - 顶部预留可拖拽区域移动窗口（`data-tauri-drag-region`）。
  - 退出摸鱼 / 隐藏按钮。
- 全局老板键：默认一个快捷键，随时隐藏/呼出窗口（即使窗口不在前台）。
- 进入摸鱼时自动收起非必要 UI，仅保留指板（参考或练习其一）。
- 窗口偏好（透明度/置顶/缩放/上次大小）持久化。

## 7. 发音逻辑
- 频率：`f = 基准 * 2^(半音数/12)`，基准用 A4=440Hz 反推各空弦音，再按品偏移。
- 用 OscillatorNode（三角波/正弦混合）+ 短促 ADSR 包络模拟拨弦衰减。
- 首次交互后再创建/恢复 AudioContext（满足浏览器自动播放策略）。

## 8. 错误处理与边界
- AudioContext 不可用或被浏览器拦截时：静默降级，仅视觉，不报错打断。
- localStorage 读写失败（隐私模式）：忽略持久化，功能正常。
- 窄屏：指板容器横向滚动，工具栏换行。
- 非 Tauri（纯浏览器）环境：`useWindow` 降级为 no-op，摸鱼开关隐藏/置灰，其余功能正常。
- 全局快捷键注册失败（系统占用）：提示并允许改键或忽略，不影响主功能。
- 透明窗口在部分系统/显卡下可能不完全透明：以"半透明背景"兜底，不崩。

## 9. 测试策略
- **单元测试**（Vitest）：
  - `useFretboard`：抽样校验若干 (弦,品)→音名（如 5弦3品=C、1弦0品=E、3弦9品=E）。
  - 简谱映射、指型归属表的正确性。
  - `useQuiz`：判分、连对计数、范围过滤出题。
- **组件测试**：点击音点触发高亮 + info 更新；练习选项判对错。
- **手动验证**：浏览器中跑一遍参考/练习两模式、三内容、发音开关；
  Tauri 应用中验证摸鱼模式（透明/置顶/缩放/老板键）。
